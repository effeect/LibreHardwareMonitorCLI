# LibreHardwareMonitorCLI
This is a wrapper for LibreHardwareMonitor that allows a CLI functionality to dump all the values, this can be used in other porgrams/wrappers such as a powershell script or anything similar to that.

The final solution will be a compiled exe that will act the same way as OpenHardwareMonitorReport does.

Additional features to be added :
- A way to filter specific data if needed
- A `-t` option that could allow the exe to keep on reporting if needed
